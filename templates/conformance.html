How to read the states

OK Exact match

The observed state matches the declared contract exactly (e.g. SHA-256 hash verified, service active, file present, or SSH link verified).

error Verified mismatch / drift

A check ran cleanly and verified a structural mismatch, missing path, stopped service, or failed SSH authentication.

unknown Probe execution failure

The collector probe could not complete execution (e.g. remote host unreachable or probe timeout). Unknown states represent unverified assertions.

warning Advisory / Unknown aggregation

Reserved for advisory drift or unverified conditions. Any check returning unknown automatically elevates the overall status to warning.

What green does not prove

Not complete fleet health

Conformance verifies static declared contracts and accessibility rules, not overall fleet application health, memory usage, or active workload status.

Not Temple/Lookout/full six-host SSH

Monitored inter-host SSH matrix checks core execution hosts (alpha, charlie, delta, macbook). It does not test all 6 hosts or ancillary nodes like Temple and Lookout.

Not provider auth or quota

Does not test external LLM provider API credentials, rate limits, credit balance, or model quotas.

Not application behavior

Does not execute application business logic, test HTTP handler behavior, or validate user interface workflows.

Not NAS or GPU health

Excludes network-attached storage (/mnt/nas, /mnt/nas2) mounts and GPU accelerator hardware state.

Not a restore drill

Snapshot freshness confirms backup archive file age and presence, not full database restoration viability or restore drill success.

Cache timestamp matters

All evidence displayed here is derived from the background collector snapshot generated at {{ projection.generated_at_central }} Central. Cached green status reflects the state at collection time and can outlive live host changes if background collection is stalled or delayed.

Heartbeat Distinction: The Health Timeline on the main Nexus dashboard is a separate machine-heartbeat surface tracking 5-minute system telemetry and daemon pulses, distinct from this 15-minute declarative drift collection service.
